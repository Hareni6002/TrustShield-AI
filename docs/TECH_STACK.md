# TrustShield AI — Technical Stack

- Frontend: React 19, Vite, Framer Motion, Lucide React
- Backend: Python 3.13, FastAPI, Uvicorn, Pydantic
- Analysis: URL, DNS, SSL, HTTP, domain, brand and lexical engines
- ML: scikit-learn model with feature extraction and probability output
- Explainability: SHAP-compatible explainability service with top risk/trust factors
- Reputation: VirusTotal, Google Safe Browsing and URLhaus adapters
- AI: Gemini provider with deterministic fallback and prompt-safety checks
- Database: SQLite via SQLAlchemy for history, reports and network metadata
- Reporting: ReportLab PDF generation from stored scan data
- Security: SSRF/private-network validation, backend-only secrets, CORS allow-list
- Visualization: React CSS/SVG visualizations and Framer Motion transitions
